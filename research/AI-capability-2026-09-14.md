# CMP 90HX 单卡 AI 能力实测（2026-09-14）

一台 10GB 矿卡（已解锁算力 + PCIe Gen2）能跑什么、跑多快 —— 全部本机实测。
分子报告：[`llamacpp/qwen3.8-27b-iq2/`](llamacpp/qwen3.8-27b-iq2/REPORT.md)、[`comfyui/chisa-lora-sdxl/`](comfyui/chisa-lora-sdxl/REPORT.md)

## TL;DR

| 能力 | 实测结果 |
|---|---|
| **27B 大语言模型（2bit）** | 单卡 10GB 完整放进显存，冷启动 **3.7 s**，生成 **35.5 tok/s**，预填充 **840 tok/s**，上下文 **32k** |
| **看图（多模态）** | 27B VL 能准确描述图片（红丝带/红瞳/水手服全对）；768×1024 图 ≈ 787 token |
| **投机解码（ngram-mod）** | 复制/改写类任务 **2.45–2.71×**（35→96 tok/s），极限 231 tok/s，零显存零下载 |
| **SDXL 出图** | 1024²/24 步 **10.9 s**；批量 4 张 **11.2 s/张**；全程 250 W 顶墙无降频 |
| **4K 出图** | 直接生成 **107 s**；1344×768 + 4x-UltraSharp **19.4 s**（推荐） |
| **自训角色 LoRA** | 16 张图 / 960 步 / **56 分钟**，角色一致性肉眼可见 |
| **单卡硬限制** | 27B-LLM（9.0 GB）与 SDXL（9.7 GB）**不能同时常驻**，10GB 需二选一 |

## 2. 语言模型：Qwen3.8-27B（2bit）

官方 fp16 权重 55.6 GB，10GB 卡必须量化：**GGUF IQ2_XXS 6.76 GiB（2.0625 bpw）**。

| 指标 | 实测 |
|---|---|
| 冷启动 | 3.69 s |
| 显存 | 常驻 9012 MiB / 峰值 9258 MiB（32k ctx，KV q8_0） |
| llama-bench | pp512 **797 t/s**、pp4096 **842 t/s**、tg **35.8 t/s**（f16 KV；q8_0 KV 为 793/839/35.4） |
| 有效带宽 | 6.76 GiB × 35.5/s ≈ **258 GB/s**（标称 760，2bit kernel 只用出 1/3） |
| TTFT | 112 tok → 0.40 s；2,511 tok → 3.29 s；30,011 tok → 43.3 s |
| 上下文上限 | **32,768**（输入 ≈32,745 上限，超出 HTTP 400）；8k/16k 可 f16 KV，32k 必须 q8_0，64k OOM |
| 多模态 | 看图问答正确，3.3 s，峰值 9258 MiB |
| Agent 化 | OpenAI 兼容接口 + 函数调用 + 思考链；已接入 pi 并验证工具调用（模型自跑 `uname -r`） |

## 4. 结论（视频可直接用的点）

**能做**
1. 本地 27B 大模型：10GB 卡 + 2bit 量化 → 35 tok/s 生成、3.7 s 冷启动，够日常问答/文档总结/代码改写，可当编程 Agent 后端。
2. 本地多模态图文问答，同一套权重。
3. 本地 SDXL 出图：1024² 约 11 s，4K 约 19 s（两步法）；角色 LoRA 自训 <1 小时。
4. 全部本地推理、零 API 费用；出图全程 250 W 顶墙、SM 1830 MHz、60 °C 以内。

**做不到 / 要取舍**
1. 上下文只有 32k（模型原生 262k）；64k 需换 KV q4 或加显存。
2. 2bit 量化有代价：复杂长链推理弱于原版（本项目实测四则运算/看图正常）。
3. **10GB 显存只能二选一**：LLM 9.0 GB vs SDXL 9.7 GB；同时服务需要第二张卡（TP 不可行，见 `p2p/`）。
4. 直接 4K 生成显存吃到 9.86 GB，接近上限，不建议并发。
