## 分镜 2 ｜ 一句话背景（0:12 – 0:30）

**画面**：仓库首页 / 解锁前后对比表

**解说词**
> 这张卡原始状态算力被锁到 0.72 TFLOPS，PCIe 只有 Gen1。解锁之后单精度 18 TFLOPS、PCIe Gen2 全速，翻 25 倍。解锁方法和坑都在这个开源仓库里，今天只看它跑 AI 的成绩。

**数据卡**：`0.72 → 18.24 TFLOPS` ｜ `Gen1 → Gen2 x16`

## 分镜 3 ｜ 大模型部署（0:30 – 1:25）★核心数据

**画面**：终端敲启动命令 → 服务起来 → 打一个问题 → 可选：开个 `nvidia-smi` 看显存

**操作**
```bash
sudo systemctl start llama-qwen38      # 启动后立刻开始计时
llama-server ... -m Qwen3.8-27B-UD-IQ2_XXS.gguf -ngl 99 -c 32768 ...
```

**解说词**
> 27B 模型原版 fp16 要 55 个 G，10GB 卡根本放不下。我压到 2bit —— 量化后 6.76GB，**整份权重全部进显存**，占了 9.0G。
> **冷启动 3.7 秒**。
> 生成速度：**每秒 35.5 个 token**；预填充 **每秒 840 个 token**，输 2500 字的首字延迟只要 **3.3 秒**。
> 上下文我开到 **32K**，一张 768×1024 的图大概占 800 token，看图也能用。
> 另外开了一个零成本的投机解码，复制、改写这类活能再快 2.5 倍。

**数据卡（建议直接贴屏）**
| 指标 | 数值 |
|---|---|
| 模型体积 | 6.76 GB（fp16 原版 55.6 GB → 2bit） |
| **冷启动** | **3.7 s** |
| 显存占用 | 9.0 GB / 10 GB |
| **生成速度** | **35.5 tok/s** |
| 预填充 | 840 tok/s |
| 首字延迟 | 112 字 → 0.4s ｜ 2,511 字 → 3.3s |
| 上下文 | 32K |

**讲解备注**（被问到才展开）：跑满时显存带宽约 258 GB/s，说明瓶颈在显存不在算力；2bit 的解量化核只能吃出标称 760GB/s 的三分之一。
